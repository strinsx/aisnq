# AISNQ

AISNQ is a study app for organizing learning material into notes and practice. This branch contains the visual foundation and project context.

## Run locally

1. Install dependencies with `npm install`.
2. Start the development server with `npm run dev`.
3. Open [http://localhost:3000](http://localhost:3000).

The UI uses shadcn/ui components with Base UI primitives and the tweakcn theme specified in `context/feature-spec/01-design.md`. Inter, Playfair Display, and JetBrains Mono are bundled locally under `app/fonts/` and covered by [the OFL license](app/fonts/OFL.txt).
