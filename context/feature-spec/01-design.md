Install and configure `shadcn/ui`.

Add these shadcn components:
- Button
- Table
- Card
- Dialog
- Toast
- Alert
- Tabs
- Skeleton
- Alert Dialog
- Calendar
- Data Table
- Context Menu
- Dropdown Menu
- Empty
- Field
- Menubar
- Questionnaire

Do not modify `/components/ui` files after installation.

Also install `npx shadcn@latest add https://tweakcn.com/r/themes/cmlm03etv000204lh15608kec`

Configure this as it would serve as the main global theme for this project.

Also install `lucide-reacts`

Create `lib/utils.ts` with a reusable `cn()` helper for merging Tailwind classes.
